UN Bangla font (UNDP, free to use) — put the files here, named exactly:

  UNBangla-Regular.woff2   (or .ttf)   weight 400
  UNBangla-Bold.woff2      (or .ttf)   weight 700
  UNBangla-Light.woff2     (or .ttf)   weight 300   (optional)

Download the Unicode version from UNDP Bangladesh's "UN Bangla Font" page.
If you only have .ttf files, just use .ttf names — both are supported.
Until the files are here the app falls back to Noto Sans Bengali.
